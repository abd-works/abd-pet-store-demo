# Increment folders

Each folder is named **`<n>-<slug>`** — increment number plus kebab-case slug from the marketable name in [`../end-to-end/discovery/stories/thin-slicing.md`](../end-to-end/discovery/stories/thin-slicing.md).

| Folder | Increment |
| --- | --- |
| `1-walk-in-driver` | Walk-in driver — find the store, see what's in stock |
| `2-click-and-collect` | Click-and-collect — buy online, pick up at the store |
| `3-ship-to-home` | Ship to home — full standard-delivery e-commerce |
| `4-returning-customers` | Returning customers — accounts, history, reorder |
| `5-pay-your-way` | Pay your way — multi-vendor payment with retries |
| `6-pet-visits` | Pet visits — gallery and in-store appointments |
| `7-returns-refunds` | Returns and refunds — close the loop |
| `8-marketing-engine` | Marketing engine — reviews, alerts, and content |
| `9-power-ups` | Power-ups — search, personalization, admin polish |

Each folder contains flat stage subfolders: `exploration/`, `specification/`, `engineering/`.
